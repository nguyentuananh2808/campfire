# Roadmap

After the Identity, Groups, Chat and Events MVP is complete and piloted:

- Funds: decimal amounts plus ISO currency, explicit rounding, immutable audit and reconciliation; Campfire never holds user funds.
- Plans: reusable checklist, assignment and itinerary features without premature AI integration.
- Werewolf extensions: configurable role packs beyond Villager/Werewolf/Seer/Guard/Witch, nomination rules, Hunter/Cupid, configurable public/secret voting, host-controlled voting voice, turn-based speaking, licensed sound announcements and richer match history.
- Voice extensions: production TURN/TLS deployment, ordered speaking mode and optional dead-channel moderation. Recording remains opt-in only.

Funds and Plans remain roadmap-only; no empty project or service is created for them.
