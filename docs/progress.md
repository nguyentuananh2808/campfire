Docker Desktop is installed; PostgreSQL 18 and LiveKit run locally, all module migrations apply successfully and the API health checks pass.
- M2 Identity is code-complete across Angular, API, Application and Infrastructure. Registration, login, current-account lookup, current-password-protected password change, session invalidation and logout use ASP.NET Core Identity, EF Core and PostgreSQL.
- M3 Groups is code-complete across Angular, API, Application, Domain and Infrastructure. It supports create/rename/list, member viewing/removal/leaving, expiring invitation creation/list/revocation/preview/join and transactional ownership transfer without group deletion.

It supports member-scoped history, stable before/after cursors, race-safe idempotent send, post-commit realtime notification, reconnect reconciliation, live membership revocation and optimistic pending/sent/failed retry UI.

It supports bounded group lists, detail, future-only create/edit, creator/owner management, versioned state transitions, `Open`-only atomic RSVP, explicit unanswered members and historical RSVP markers after membership ends.
- M8 Werewolf is code-complete for the first playable ruleset across Angular, REST/MediatR, SignalR, a server-authoritative phase worker, LiveKit voice authorization and its own PostgreSQL schema. It supports public/private lobbies, code/link join, ready/start/reconnect/host transfer, five metadata-complete basic roles, domain-enforced phase order, independently tested night/vote resolution, payload-safe action idempotency, private role/action projections, timeout fallback, win detection and phase-scoped living/Wolf/dead voice.
- Every module follows the mandatory interaction boundary `API endpoint -> ISender (MediatR) -> command/query handler -> DI-injected Application interface -> Infrastructure implementation -> ASP.NET Core Identity/EF Core/PostgreSQL`. Architecture tests enforce the MediatR references.
- Identity registration accepts only email, password and display name and never assigns a role. Cookie authentication is HttpOnly, antiforgery protects mutations, lockout is enabled and password change rotates the security stamp while refreshing only the current session.
- The Angular client has real lazy login, registration and profile/password/logout flows, typed HTTP access, route protection and loading/error states. Authentication material is not stored in browser storage.
- The Angular Groups feature has real list/create, detail/member management, owner transfer, invitation management and confirmation-only invite acceptance screens. Raw invite tokens use URL fragments and are removed from the address bar before preview; only explicit POST confirmation joins a group.
- The frontend owns a Campfire color library with semantic design tokens and a persisted light/dark theme. Its primary visual language uses amber, orange, red and ember tones inspired by a campfire.
- The authenticated mobile shell has a safe-area-aware fixed bottom navigation for Trò chuyện, Kèo, Ma Sói and Nhóm. Content reserves its height, active destinations are announced and highlighted, and the Chat composer stays above the navigation without horizontal overflow.
- Password recovery, email confirmation and email delivery are deliberately absent because no email provider is configured. Public registration must not be opened broadly until those recovery and verification capabilities exist; the UI does not expose fake actions.
- M9 Stranger Chat is implemented across isolated Domain/Application/Infrastructure/Presentation/Contracts projects, an initial PostgreSQL migration, REST/MediatR endpoints, guest-cookie security, random matching, persisted idempotent text, SignalR notifications, block/report controls and a mobile-first Angular route.
